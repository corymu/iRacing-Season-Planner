# iRacing Season Planner

Pick the cars and tracks you own, set your license, and see every race you can run this season, ranked by what you like. Runs entirely in your browser: no account, no server, nothing uploaded.

Unofficial fan tool. Not affiliated with or endorsed by iRacing.com Motorsport Simulations.

## Update for a new season
Maintainer only: parse the season PDF, run `python3 export_web.py` in the planner project, then copy the `web/` files here and push.
